# foundation

Resources that outlive the cluster: the `eks-platform/api` ECR repository, the database password in Secrets Manager, the `lab.<domain>` hosted zone and its ACM certificate. Applied once and kept; `make up` and `make down` do not touch it.

## Design

ECR tags are immutable, so a deployed Git SHA always means the same image. Images are scanned on push for OS package CVEs, and only the 20 most recent are kept.

The password is generated by an ephemeral `random_password` and written through the write-only `secret_string_wo`, so it never appears in plan or state. Because Terraform cannot read a write-only value back, it only writes the secret when `db_password_version` changes. The secret is JSON with a `password` key, which the chart's `ExternalSecret` reads.

The zone covers `lab.<domain>` only; the parent domain stays at its own DNS provider and delegates to it ([ADR 0010](../../docs/adr/0010-dns-delegated-lab-subdomain.md)). The parent domain is set in the gitignored `terraform.tfvars`. The zone has `prevent_destroy` and no `force_destroy`, because a recreated zone gets new name servers and the delegation would have to be redone.

The certificate covers `lab.<domain>` and `*.lab.<domain>` and lives in the cluster's region. The Load Balancer Controller finds it by the Ingress host, so nothing needs its ARN ([ADR 0014](../../docs/adr/0014-ingress-via-aws-load-balancer-controller.md)). ACM renews it as long as the validation CNAME stays in the zone.

## Usage

```bash
cp terraform.tfvars.example terraform.tfvars   # set owner and domain_name
cp backend.hcl.example backend.hcl             # replace <account-id>
terraform init -backend-config=backend.hcl
terraform plan -out=tfplan
terraform apply tfplan
```

### Delegate `lab.<domain>`

This is a one-time manual step at the parent domain's DNS provider. Create an `NS` record named `lab` with the four values from `terraform output lab_zone_name_servers`, then check it:

```bash
dig +short NS lab.<domain>                     # the four Route 53 name servers
```

The certificate only validates once the delegation resolves. If the first apply times out waiting for it, apply again.

```bash
aws acm list-certificates --query 'CertificateSummaryList[].[DomainName,Status]' --output table   # ISSUED
```

### Rotate the database password

```bash
terraform apply -var db_password_version=2
```

PostgreSQL only reads the password when it initialises an empty data directory. After a rotation, run `make undeploy` and `make deploy` to recreate the volume, or change the password inside PostgreSQL to match.

## Cost and teardown

Under $1 per month plus $0.10 per GB-month of images; the public certificate is free. A `terraform destroy` fails while the repository still holds images, and fails on the zone until its `prevent_destroy` block is removed in a reviewed change. The secret stays recoverable for 7 days. After destroying the zone, remove the `lab` `NS` records at the parent domain.
